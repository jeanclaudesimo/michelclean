# MichelClean Logo Assets

Hochauflösende Logo-Dateien für geschäftliche Dokumente, Rechnungen und Marketing.

## 📁 Verfügbare Dateien

### Für Rechnungen und Dokumente (empfohlen)

**logo-invoice-high.png** (1200x400px)
- Höchste Auflösung für Drucksachen
- Perfekt für: Briefköpfe, A4-Dokumente, Poster
- Mit Kontaktinformationen

**logo-invoice.png** (900x300px)
- Standard-Auflösung für digitale Rechnungen
- Perfekt für: PDF-Rechnungen, Word-Dokumente, E-Mails
- Mit Kontaktinformationen

**logo-invoice-medium.png** (600x200px)
- Mittlere Auflösung für kleinere Dokumente
- Perfekt für: Angebote, Lieferscheine
- Mit Kontaktinformationen

### Kompakte Logos (ohne Kontaktinfo)

**logo-compact-high.png** (1000x280px)
- Kompaktes Logo in hoher Auflösung
- Perfekt für: Website-Header, Präsentationen

**logo-compact.png** (750x210px)
- Kompaktes Logo in Standard-Auflösung
- Perfekt für: Social Media Cover, Newsletter

### Icon-Varianten

**logo-icon-high.png** (400x400px)
- Nur das Icon in hoher Auflösung
- Perfekt für: Stempel, quadratische Flächen

**logo-icon.png** (300x300px)
- Icon in Standard-Auflösung
- Perfekt für: Profilbilder, App-Icons

**logo-icon-small.png** (200x200px)
- Kleine Icon-Version
- Perfekt für: Favicons, kleine Badges

## 🎨 Verwendungshinweise

### Für Rechnungen
Verwenden Sie **logo-invoice.png** (900x300px) - diese Datei enthält:
- Das vollständige Logo
- Tagline "PROFESSIONELLE REINIGUNGSDIENSTE"
- Kontaktinformationen (Telefon, E-Mail, Adresse)
- Optimale Größe für A4-Rechnungen

### Für Word-Dokumente
1. **Rechnung/Briefkopf:** logo-invoice.png
2. **Angebot:** logo-invoice-medium.png
3. **Präsentation:** logo-compact-high.png

### Für E-Mail-Signaturen
Verwenden Sie **logo-compact.png** (750x210px)

### Für Social Media
- **Profilbild:** logo-icon.png (300x300px)
- **Cover/Banner:** logo-compact-high.png

## 🔄 Logos neu generieren

Falls Sie die Logos anpassen oder neu generieren möchten:

```bash
npm run generate-logos
```

Dies erstellt alle Logo-Varianten neu aus den SVG-Vorlagen.

## 📝 Farben

- **Primary Blue:** #3a4b7c (Michel)
- **Accent Green:** #10b981 (Clean & Icon)
- **Text Gray:** #6b7280 (Tagline)
- **Light Gray:** #9ca3af (Kontaktinfo)

## 💡 Tipps

1. **Für Rechnungen:** Fügen Sie das Logo oben links oder zentriert im Dokument ein
2. **Größe in Word:** Ca. 8-10cm Breite für optimale Lesbarkeit
3. **Hintergrund:** Alle PNGs haben transparenten Hintergrund, funktionieren auf jedem Untergrund
4. **Druck:** Verwenden Sie die "-high" Versionen für beste Druckqualität
